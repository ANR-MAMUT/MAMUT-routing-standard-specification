\begin{abstract}
We specify how static MAMUT-routing instances acquire numerical meaning, how solutions are checked and ranked, and how authoritative results are preserved. The specification separates generation, instance, evaluation and result semantics. The standard retains binary64 interpretation after generation or matrix rederivation. Exact evaluation then operates on those finite values, including time-window feasibility, without intermediate rounding. Integer-valued families admit an equivalent integer implementation. Decimal and decimal-grid interpretations remain explicitly identified alternatives. Each benchmark revision selects its authority, while solvers may use different arithmetic internally. We provide pseudocode, an executable Python reference, conformance examples and proposed result metadata. This document is a draft for review before library changes or incumbent migration.
\end{abstract}
