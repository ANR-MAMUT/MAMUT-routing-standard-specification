# Repository history

This repository continues the MAMUT-routing specification originally kept in a `mamut-routing-standard/` directory of the authors' report repository. It was extracted with its Git history on 26 October 2026, using `git subtree split --prefix=mamut-routing-standard HEAD`, which preserves the committed tree, author identity, author date, commit message and coauthor trailer of each commit. The commit identifiers change because the directory becomes the repository root, and unrelated report history is excluded.

| Original report commit | Extracted repository commit |
|---|---|
| `26972706f9fec4dda1350a17c33b4f28de19494e` | `3317ece848d6d24b64db58844d2bc44805c2bcc3` |

The extraction moved no benchmark edition, best-known solution, production checker or website. Earlier sections on measured evidence, family adoption and historical comparisons between library releases, together with their validation records, were removed from version 0.1 of the specification and remain available in the Git history of this repository.
